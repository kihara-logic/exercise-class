原点で連続か？ ε-δ で決着をつける

演習の問題4の2つの関数を調べます．どちらも f(0, 0) = 0 と定めます． (1)　f = 2x²yx² + y²　 (2)　f = 2xyx² + y²

(0, 0) で連続とは：どんな ε > 0 に対しても，|x| < δ ならば |f(x) − f(0, 0)| < ε となる δ > 0 がとれること．これを「相手が ε を出し，あなたが δ で答える」ゲームとして体験します．
